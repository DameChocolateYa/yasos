# Contributing to yasos

Thank you for your interest in contributing to yasos! This document provides guidelines and instructions for contributing to the project.

## Code of Conduct

Please review our [Code of Conduct](CODE_OF_CONDUCT.md) before participating. All contributors are expected to uphold these standards.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/yasos.git`
3. Add upstream remote: `git remote add upstream https://github.com/DameChocolateYa/yasos.git`
4. Create a feature branch: `git checkout -b feature/your-feature-name`

## Development Setup

Please refer to the project's README for setup and build instructions.

## Making Changes

### Code Style

- Follow the existing code style and conventions in the repository
- Ensure your code is properly formatted and readable
- Include comments for complex logic

### Commits

- Write clear, descriptive commit messages
- Keep commits focused on a single change or feature
- Reference relevant issues in commit messages when applicable

### Testing

- Test your changes thoroughly before submitting a pull request
- Add tests for new functionality
- Ensure all existing tests continue to pass

## Submitting Changes

1. Push your changes to your fork
2. Submit a pull request against the `main` branch
3. Provide a clear description of your changes and why they're needed
4. Reference any related issues

## Pull Request Process

- Ensure your PR description clearly explains the changes
- Be prepared to respond to feedback and make revisions
- Maintain a respectful and professional tone in discussions
- Your PR will be reviewed before merging

## Reporting Issues

When reporting bugs or suggesting features:

- Use the issue templates provided
- Include relevant details and context
- Be as specific as possible in your description
- Avoid duplicate issues by searching first

## Questions?

Feel free to open an issue or reach out to the maintainers if you have questions.
